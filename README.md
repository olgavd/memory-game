# Memory-game

### Memory-game - это игра на поиск пар: игрок открывает карточки и запоминает их расположение, чтобы найти все совпадения за наименьшее число ходов.

## 🚀 Локальный запуск (Local Development)

Для запуска проекта на локальном сервере используется расширение **Live Server** для Visual Studio Code. Это позволяет автоматически обновлять страницу в браузере при сохранении изменений в коде.

### Предварительные требования
1. Установленный редактор **Visual Studio Code**.
2. Установленное расширение **Live Server** (автор: *Ritwick Dey*). Найти его можно во вкладке Extensions (`Ctrl+Shift+X` или `Cmd+Shift+X` на Mac), введя в поиск "Live Server".

### Инструкция по запуску

1. **Откройте проект** в VS Code: `File` -> `Open Folder...` (выберите папку с проектом).
2. **Запустите сервер** одним из следующих способов:
   * Нажмите кнопку **Go Live** в правом нижнем углу строки состояния (Status Bar) VS Code.
   * Нажмите правой кнопкой мыши на файл `index.html` в проводнике и выберите **Open with Live Server**.
   * Используйте горячие клавиши: `Alt + L, Alt + O` (`Cmd + L, Cmd + O` на Mac).

Проект автоматически откроется в вашем браузере по умолчанию (обычно по адресу `http://127.0.0.1:5500`).

### Остановка сервера
Чтобы остановить сервер, нажмите на кнопку **Port: 5500** в строке состояния VS Code или используйте комбинацию клавиш `Alt + L, Alt + C` (`Cmd + L, Cmd + C` на Mac).
